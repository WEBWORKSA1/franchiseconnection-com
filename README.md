# FranchiseConnection.com

Independent franchise matchmaking and due-diligence hub: brand-neutral category data, calculators, guides, live franchise news, and lead generation for franchisors. Static site on GitHub Pages (free plan, `main` branch, root). GitHub Pages builds it with Jekyll on every push; there is no build step to run yourself.

## Structure
| Path | What it is |
|---|---|
| `src/pages/**/*.html` | Page bodies (edit these). Each starts with a `<!--meta ... -->` note; the live front matter is in the matching stub. |
| `*.html`, `guides/*.html` | Stubs: front matter (title, description, nav section, article fields) plus one include of the body |
| `_layouts/fc.html` | Shared head (AdSense, SEO, JSON-LD), header, top contact strip, footer, article frame |
| `_config.yml` | Jekyll settings (`includes_dir: src/pages`) |
| `sitemap.xml`, `sitemap.html` | Generated by Jekyll from the stubs on every build |
| `assets/css/site.css`, `assets/js/site.js` | All styles and behaviour, no frameworks |
| `data/concepts.json` | 75 franchise categories (generated by `tools/make_concepts.py`) |
| `data/news.json` | Fallback headlines; the news page also pulls live Google News results in the browser |
| `automation/refresh.yml` | Optional daily data job (see below) |
| `BUILD-PROMPTS.md`, `RESEARCH.md` | Phase-wise build prompts and the competitive research |

## Add or edit a page
1. Edit or add the body in `src/pages/` (links as `{{root}}page.html`).
2. For a new page, copy any stub at the root (or in `guides/` for an article), change its front matter and the include path.
3. Commit. Pages rebuilds in about a minute; the sitemaps update themselves.

## What updates on its own
- **News**: `news.html` and the home page merge live Google News searches (via rss2json, cached one hour per visitor) with `data/news.json`.
- **Events**: past expos disappear and countdowns tick automatically.
- **Contests**: monthly and quarterly deadlines roll forward automatically.
- **Sitemaps and asset versions**: regenerated on every build.
- **Optional daily job**: create `.github/workflows/refresh.yml` with the contents of `automation/refresh.yml` to refresh `data/news.json` daily and generate the social images if they are missing.

## Monetization switches
- **AdSense**: the publisher script and `google-adsense-account` meta are in every page head; `ads.txt` is at the root. Turn on Auto ads in AdSense. For manual units, add slot IDs to `AD_SLOTS` at the top of `assets/js/site.js`; every `.ad-slot` placeholder then renders a unit.
- **Leads, donations, contests, applications**: every form posts through FormSubmit to the private inbox, which is stored only as an obfuscated array in `site.js` and never appears as text. The first submission triggers a one-time FormSubmit activation email to that inbox: click **Activate**.
- **Top strip** on every page links to https://web.works/contact.

## Publish
Settings → Pages → Build and deployment → Source **Deploy from a branch** → Branch **main**, folder **/ (root)** → Save.

## Custom domain
1. DNS at the registrar: `A` records for `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`; `CNAME` for `www` → `webworksa1.github.io`.
2. Settings → Pages → Custom domain: `franchiseconnection.com` → Save → tick **Enforce HTTPS** once the certificate is issued.

All internal links are relative, so the site works on both `webworksa1.github.io/franchiseconnection-com/` and the custom domain.
