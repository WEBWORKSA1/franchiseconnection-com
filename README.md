# FranchiseConnection.com

Independent franchise matchmaking and due-diligence hub: brand-neutral category data, calculators, guides, daily franchise news, and lead generation for franchisors. Static site, built for GitHub Pages (free plan, `main` branch, root).

## Structure
| Path | What it is |
|---|---|
| `src/pages/**/*.html` | Page content fragments (edit these) |
| `build.py` | Wraps fragments in the shared head/header/footer, writes the HTML to the repo root, builds `sitemap.xml` and the HTML sitemap |
| `assets/css/site.css`, `assets/js/site.js` | All styles and behaviour, no frameworks |
| `data/concepts.json` | 75 franchise categories (generated by `tools/make_concepts.py`) |
| `data/news.json` | Franchise headlines (refreshed daily by `tools/fetch_news.py`) |
| `tools/make_images.py` | Draws the logo and social-share image |
| `.github/workflows/refresh.yml` | On every push to `src/`, `assets/`, `tools/` or `build.py`: rebuilds the site. Daily: refreshes news. Commits the result. |
| `BUILD-PROMPTS.md`, `RESEARCH.md` | Phase-wise build prompts and the 37-site competitive research |

## Edit and rebuild
Edit files in `src/pages/` (or the CSS/JS) and push — the workflow rebuilds every page and the sitemap automatically. To build locally:
```bash
python3 tools/make_concepts.py   # category data
python3 build.py                 # regenerate every page + sitemap
```

## Monetization switches
- **AdSense**: the publisher script and `google-adsense-account` meta are in every page head; `ads.txt` is at the root. Turn on Auto ads in AdSense. For manual units, add slot IDs to `AD_SLOTS` at the top of `assets/js/site.js` — every `.ad-slot` placeholder then renders a unit.
- **Leads, donations, contests, applications**: every form posts through FormSubmit to the private inbox, which is stored only as an obfuscated array in `site.js` and never appears as text. The first submission triggers a one-time FormSubmit activation email to that inbox — click **Activate**.
- **Top strip** on every page links to https://web.works/contact.
